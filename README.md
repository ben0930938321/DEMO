# Alex Chen Portfolio

A small portfolio website documenting selected architecture and computational
design work.

## Site Structure

The website contains a home page and an about page.

Project information is loaded dynamically from a JSON file.

## Files

- `index.html` — main portfolio page
- `about.html` — profile page
- `style.css` — visual styles
- `script.js` — project loading and website behavior
- `projects.json` — project information

## Development

This site is maintained using Git for version control.
